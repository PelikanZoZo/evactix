# Журнал версий Evactix

Версия продукта — в файле `VERSION`. При её изменении в `main` GitHub сам ставит метку `v<версия>`
и публикует релиз с описанием из этого файла.

## [1.0.0] — 2026-11-01

Первая версия: технологическое ядро и сторож.

### Ядро
- Хранилище событий и планов по модели «ТЗ ядра Evactix: модель данных»: PostgreSQL 16 + TimescaleDB,
  сжатие старых данных, только дописывание, поправки через `supersedes`, подпись цепочки по каждому источнику.
- Модель события (конверт, место, субъекты, источник и доверие, связи) и плана (параметр, допуск, версии);
  10 типов значений.
- Валидатор на входе: без физлиц и ИП, без реквизитов, телефонов и email, без свободного текста,
  только метрики из справочника. Отказы — в журнал (причина и отпечаток).
- Роли базы: владелец, `collector` (только дописывает), `ana` (только читает).
- Сырые данные хранятся сжатыми на диске.
- Паспорт установки `system_info`: продукт, версия, коммит, время выкатки.

### Сборщики
- ЦБ РФ: официальные курсы (история 30 дней), учётные цены драгметаллов (год), ключевая ставка (2 года).
- Производственный календарь РФ, КЗ, BY, UZ — как планы, с поправками при изменении.
- Астрономия: фаза Луны на 400 дней, восход, закат и долгота дня по 10 опорным точкам.
- Met Norway: прогноз погоды на 72 часа по 10 опорным точкам.
- USGS: землетрясения M4.5+; GDACS: оповещения о бедствиях с уровнем угрозы.

### Ана
- Отдельный проект рядом с ядром: свой образ, своё состояние, своя выкатка.
- Проверки каждые 5 минут: база ядра, диск, свежесть источников, серии ошибок, отказы валидатора, входная точка.
- Telegram: тревоги, напоминания, «в норме», ежедневная сводка в 09:00 МСК.

### Инфраструктура
- VPS-1: Docker, Caddy, брандмауэр, fail2ban, UTC, ежедневный бэкап базы.
- Выкатка ядра и Аны из GitHub Actions с тестами; пароли ролей генерируются на сервере.
- Проверка доступности источников данных с сервера.
