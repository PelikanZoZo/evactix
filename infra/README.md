# Инфраструктура Evactix (VPS-1)

Сервер настраивается кнопкой в GitHub: **Actions → «Настройка сервера VPS-1» → Run workflow**.
Повторный запуск безопасен.

| Файл | Что делает |
|---|---|
| `bootstrap.sh` | Первичная настройка: UTC и синхронизация времени, swap, Docker, пользователь `deploy`, вход только по ключам, брандмауэр (22/80/443), fail2ban, автообновления, ежедневный бэкап |
| `docker-compose.yml` | Сервисы: PostgreSQL 16 + TimescaleDB (наружу не открыт), Caddy (входная точка) |
| `Caddyfile` | Входная точка; `/health` отвечает `ok` |
| `backup.sh` | Ежедневный дамп базы в `/opt/evactix/backups`, хранится 14 дней (до появления S3) |

Секреты репозитория: `VPS_HOST`, `VPS_PORT`, `VPS_USER`, `VPS_SSH_KEY`, `POSTGRES_PASSWORD`, по желанию `VPS_KNOWN_HOSTS`.

Сервер временный (2 CPU / 2 ГБ): всё описано здесь, поэтому переезд на большой сервер — это смена секретов и повторный запуск.
