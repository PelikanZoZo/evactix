# Evactix v1

Платформа, которая ловит и продаёт моменты: на входе — поток изменений и событий, на выходе — сигнал действия.

Текущая версия — в файле [`VERSION`](VERSION), история — в [`CHANGELOG.md`](CHANGELOG.md).
Архитектура: ядро — данные, Дирижёр — действия, Ана — надзор.

## Из чего состоит

| Папка | Что это | Выкатка |
|---|---|---|
| [`core/`](core/) | Ядро: хранилище событий и планов, валидатор, сборщики | «Выкатка ядра» |
| [`conductor/`](conductor/) | Дирижёр — задания, расписания, агент, отправка, разговор в Telegram | «Выкатка Дирижёра» |
| [`ana/`](ana/) | Ана — сторож рядом с ядром, оповещения в Telegram | «Выкатка Аны» |
| [`infra/`](infra/) | Сервер VPS-1: настройка, сервисы, бэкап, список источников для проверки доступности | «Настройка сервера VPS-1» |
| `site/` | Заглушка сайта evactix.ru | отдельный workflow |

## Версии

- Версия продукта одна — в `VERSION`, ядро берёт её оттуда (тест следит за совпадением).
- На сервере версия видна в паспорте установки (таблица `system_info`), в сводках Аны и в имени образа `evactix-core:<версия>`.
- Изменение `VERSION` в `main` → метка `v<версия>` и релиз на GitHub.
